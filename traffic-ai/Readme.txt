HOW TO RUN THE PROJECT:
(Note: Heavy folders like 'venv' and 'node_modules' were removed to reduce file size. Please reinstall them as shown below.)

1. SETUP AI ENGINE (Python):
   - Open terminal in 'traffic-ai' folder.
   - Run: pip install -r requirements.txt
   - Run: python app.py

2. SETUP BACKEND (Node.js):
   - Open terminal in 'traffic-backend' folder.
   - Run: npm install
   - Run: npm start

3. SETUP DASHBOARD (React):
   - Open terminal in 'traffic-monitor' folder.
   - Run: npm install
   - Run: npm run dev

The system will be live at http://localhost:5173
